# Anthropic Reference Notes

Source reviewed: https://www.anthropic.com/ on 2026-08-27.

The current homepage uses a quiet off-white field, a minimal text-led header, and unusually generous space before the opening copy. Its visible composition allows a single short paragraph to do the work of explaining the company before introducing a large, restrained dark media surface. The page earns visual weight through scale, spacing, and contrast rather than decorative labels or pseudo-technical motifs.

For VisionFX, transfer only the general principles: a calmer header, a more open editorial hero, fewer labels, clear reading order, and one large art-directed media moment. Do not copy Anthropic’s brand identity, content, layout proportions, photography, navigation labels, or assets. VisionFX will retain its own orange action color and agency-specific proposition while removing the arbitrary numerals, standalone slash ornament, and build-receipt language.
